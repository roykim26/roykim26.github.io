# 测试计划

> 阶段 5 · v1.0 · 对应需求 `02-requirements/prd.md`、验收标准 `02-requirements/acceptance-criteria.md`

## 1. 测试目标

验证三件事：

1. **站点能用**：22 个静态路由全部可访问，内容、导航、搜索、订阅入口行为正确。
2. **站点可交付**：干净安装 → 构建 → 部署产物在多种托管环境下可用，且不依赖运行时服务端。
3. **站点可长期维护**：新增文章只需改 Markdown，不改代码；质量门禁能在 CI 中自动拦截回归。

测试对象是 `dist/` 中的构建产物，而不是开发服务器。所有人工验证均在 `npm run preview`（端口 4321）上进行。

## 2. 测试范围

### 2.1 范围内

| 领域 | 说明 |
| --- | --- |
| 路由与渲染 | 首页、文章列表、文章详情、标签总览、单标签、About、Newsletter、404、RSS、Sitemap、robots.txt |
| 内容完整性 | 10 篇已发布文章，字数、frontmatter、草稿过滤、精选标记 |
| 站内链接 | 正文内链、锚点（目录）、标签链接、页脚与导航链接 |
| SEO 不变量 | title/description 长度与唯一性、canonical、OG、JSON-LD、sitemap、RSS、robots |
| 交互增强 | 主题切换与持久化、阅读进度、目录高亮、搜索弹窗、复制链接、标签筛选 |
| 响应式 | 360 / 390 / 768 / 1024 / 1440 宽度 |
| 无障碍 | 键盘操作、焦点可见、跳转链接、语义结构、对比度、减少动效 |
| 性能 | LCP/CLS/TBT、资源体积、字体加载、缓存头 |
| 部署产物 | Docker 镜像、Nginx 配置、平台重定向、安全头 |
| 降级 | 禁用 JS 时内容可读、搜索不影响阅读、订阅表单有 RSS 回退 |

### 2.2 范围外

- 真实邮件订阅服务端（端点未配置，属于外部凭据依赖，已在 PRD 中标记为占位）。
- 真实域名解析、CDN 加速效果、第三方分析数据。
- 多语言站点、评论系统、付费内容——明确不在 v1 范围。
- 浏览器矩阵全量覆盖（Blink/Gecko/WebKit 各历史版本），仅覆盖当前主流版本。

## 3. 测试策略

| 层级 | 手段 | 触发时机 | 负责 |
| --- | --- | --- | --- |
| L1 静态检查 | `astro check`（类型 + 模板） | 每次提交 / CI | 自动化 |
| L2 构建验证 | `npm run build`（含 OG 生成、Pagefind 索引） | 每次提交 / CI | 自动化 |
| L3 结构断言 | `scripts/check-links.mjs`、`scripts/check-seo.mjs` | 构建后 / CI | 自动化 |
| L4 运行时验证 | Lighthouse（性能/无障碍/最佳实践/SEO） | 发布前 | 人工触发，结果归档 |
| L5 功能验收 | 浏览器端逐页核对 + 交互脚本 | 发布前 | 人工 |
| L6 部署演练 | Docker 本地起服务 + `curl` 冒烟 | 发布前 | 人工 |

原则：能在 L1–L3 自动化的，不放进人工清单；人工只测脚本无法判断的"看起来对不对、读起来顺不顺"。

## 5. 入口与退出标准

**进入测试**：`npm ci` 成功、`npm run build` 产出 22 个 HTML、Pagefind 索引页数 = 22。

**退出（可发布）**：AC-01 ~ AC-08 全部满足，且无 P0/P1 缺陷残留。P2 缺陷可带入 v1.1，但需在 `qa-report.md` 登记。

## 6. 缺陷分级

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| P0 | 站点白屏、构建失败、核心路由 500/404、内容丢失 | 阻断发布，立即修 |
| P1 | SEO 不变量破坏、键盘不可达、移动端横向溢出、链接失效 | 阻断发布 |
| P2 | 视觉细节、文案措辞、非关键动效、次要浏览器差异 | 记录后修 |
| P3 | 优化建议、增强想法 | 进 backlog |

## 7. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 子代理生成的英文文章存在中式表达 | 违背内容质量要求 | 逐篇抽检 + 统一润色（见 `qa-report.md` 第 5 节） |
| 无扩展名 URL 在部分静态托管下 404 | 部署后大面积失效 | 构建 `format: 'file'`；Nginx `try_files`；Vercel `cleanUrls`；Netlify/CF 重定向 |
| Pagefind 索引为空（历史上出现过） | 搜索不可用 | 在构建日志中断言 `Indexed 22 pages` |
| 字体远程加载导致 CLS/阻塞 | 性能不达标 | 系统字体栈优先，var 字体本地回退，`font-display: swap` |
| 订阅端点缺失 | 表单提交无效 | 明确降级为 RSS，文案不承诺发送频率 |
