# 验收标准与可追溯性

> Stage 2 · v1.0 · Maps requirements → verification. Executed in stage 5.

## 1. 全局发布门禁

| # | 标准 | 验证方式 | 证据 |
| --- | --- | --- | --- |
| AC-01 | 干净安装与构建 | `npm ci && npm run build` 退出码为 0 | CI 日志 / 构建日志 |
| AC-02 | 类型安全 | `npm run check` → 0 错误、0 警告 | 命令输出 |
| AC-03 | 无失效的内部链接或锚点 | `npm run test:links` → 0 失败 | 脚本报告 |
| AC-04 | 所有路由满足 SEO 不变量 | `npm run test:seo` → 0 失败 | 脚本报告 |
| AC-05 | Lighthouse ≥ 95 × 4 | 在构建预览上运行 Chrome Lighthouse | `05-qa-testing/lighthouse.md` |
| AC-06 | 无 critical/serious 级别的 axe 违规 | 手动运行 axe DevTools | `05-qa-testing/qa-report.md` |
| AC-07 | 内容完整 | 10 篇已发布文章，≥ 900 词，3 篇精选 | 内容审计 |
| AC-08 | 文档可被陌生人执行 | 逐字遵循第 6 阶段手册 | 手册签署 |

## 2. 路由覆盖

| 路由 | 必须渲染 | 必须包含 | 不得包含 |
| --- | --- | --- | --- |
| `/` | 首屏、精选、3 篇最新、标签、订阅 | 定位句、H1、RSS 链接 | 草稿、占位 lorem |
| `/blog` | 全部文章、搜索入口、标签胶囊 | 数量、年份分组、阅读时长 | 草稿、坏掉的分页 |
| `/blog/<slug>` | 完整文章、目录、分享、相关 | 标题、日期、标签、JSON-LD | 隐藏付费墙、弹窗 |
| `/tags` | 所有已使用标签、数量 | 每个标签的链接 | 空标签 |
| `/tags/<tag>` | 筛选后的列表 | 标签名、数量 | 不带该标签的文章 |
| `/about` | 简介、主题、其他渠道、colophon | 联系方式 | 编造的资历 |
| `/newsletter` | 价值主张、表单/回退、RSS | 隐私说明、发送频率 | 虚假订阅数 |
| `/rss.xml` | 有效 RSS 2.0 | 全文、绝对 URL、`en` | 草稿 |
| `/sitemap-index.xml` | 所有内容路由 | 绝对 URL | `/og/*`、`/404`、草稿 |
| `/robots.txt` | 爬取规则 | sitemap 引用 | 全站禁止 |
| `/404` | 品牌化错误页 | Writing/Tags/Home 链接 | 站点崩溃 |

## 4. 完成定义（每项需求）

1. 在代码中实现，并在构建后的站点上可见（而不仅仅是源码中）。
2. 符合设计系统 token 和响应式规则。
3. 在禁用 JS 时可用，除非该功能明确属于 JS 增强。
4. 键盘可操作且播报正确。
5. 由相关自动化检查或记录在案的手动测试覆盖。
6. 在运营者会查找的位置有文档记录。
