# 产品需求文档（PRD）

> Stage 2 · v1.0 · Product: Waystone AI — English engineering blog
> Sources of truth: `01-product-architecture/` (vision, IA, architecture)

## 1. 概述

为海外读者构建并上线一个静态的英文个人博客。站点发布长篇工程文章，以安静的编辑式阅读体验呈现内容，并通过 RSS 和邮件积累自有受众。当站点可构建、可部署、可索引、可访问，并填充了十篇实质性文章时，v1.0 即告完成。

## 2. 目标与成功指标

| ID | 目标 | 指标 | 目标值 |
| --- | --- | --- | --- |
| G-1 | 快速、稳定的阅读 | Lighthouse Performance / SEO / Best Practices / A11y | 各项 ≥ 95 |
| G-2 | 可被发现 | Sitemap 与 RSS 有效；JSON-LD 有效；每篇文章有 OG 卡片 | 100% 覆盖 |
| G-3 | 可访问 | 所有路由符合 WCAG 2.2 AA | 无已知违规 |
| G-4 | 内容深度 | 已发布文章 ≥ 900 词 | 10 篇 |
| G-5 | 受众获取 | RSS + newsletter 订阅路径 | 可用、可衡量 |
| G-6 | 可维护 | 新增文章 = 一个 Markdown 文件 + 推送 | ≤ 2 分钟上线 |

## 3. 用户画像

- **Marcus，技术创始人（次要）。** 搜索 “monolith migration checklist”，落到一篇文章，在桌面端阅读，如果声音可信就订阅。

## 4. 功能需求

### FR-1 首页
- FR-1.1 在首屏展示姓名、定位句和主要行动号召。
- FR-1.2 在大卡片中仅主推一篇 `featured` 文章；若没有，则回退到最新文章。
- FR-1.3 列出最新发布的三篇文章，包含日期、标题、描述和阅读时长。
- FR-1.4 展示使用最多的六个标签及文章数量。
- FR-1.5 提供邮件订阅表单和 RSS 链接。
- FR-1.6 首页任何位置都不得出现草稿内容。

### FR-2 文章索引（`/blog`）
- FR-2.1 按时间倒序列出所有已发布文章，并按年份分组。
- FR-2.2 提供针对标题、描述、标签和正文的关键词搜索。
- FR-2.3 搜索 UI 必须仅在交互时加载，并在无 JS 时优雅降级。
- FR-2.4 提供标签筛选胶囊；选择一个标签即就地筛选列表（不刷新页面）。
- FR-2.5 当筛选结果为空时，显示带有明确重置操作的空白状态。
- FR-2.6 显示已发布文章总数。

### FR-3 文章页（`/blog/[slug]`）
- FR-3.1 渲染 frontmatter（标题、作为导语的描述、日期、更新日期、标签）以及计算出的阅读时长。
- FR-3.2 渲染 Markdown，包括标题、列表、表格、引用、行内代码、带语法高亮的围栏代码块，以及带尺寸的图片。
- FR-3.3 从 `h2`/`h3` 生成目录；宽屏吸顶、移动端可折叠；滚动时高亮当前章节。
- FR-3.4 显示阅读进度指示器。
- FR-3.5 提供 X、LinkedIn 和复制链接的分享操作。
- FR-3.6 显示作者卡片、上一篇/下一篇，以及最多三篇相关文章（共享标签）。
- FR-3.7 输出 `BlogPosting` JSON-LD，包含 headline、日期、作者、图片和字数。
- FR-3.8 未发布/草稿的 slug 必须返回 404。

### FR-4 标签
- FR-4.1 `/tags` 列出每篇已发布文章使用过的所有标签及数量。
- FR-4.2 `/tags/[tag]` 列出该标签下已发布的文章，按最新优先。
- FR-4.3 未知或未使用的标签返回 404。

### FR-5 关于
- FR-5.1 说明站点作者是谁、内容涵盖什么，以及如何联系。
- FR-5.2 包含其他渠道链接（GitHub、X、email）以及描述技术栈的 colophon。

### FR-6 Newsletter（`/newsletter`）
- FR-6.1 陈述价值主张、发送频率和隐私立场。
- FR-6.2 提供邮件收集表单，提交到可配置的服务商端点；未配置时，显示 mailto 回退，而不是一个坏掉的表单。
- FR-6.3 提供 RSS 作为替代方案。

### FR-7 分发与 SEO
- FR-7.1 `/rss.xml` 返回有效的 RSS 2.0，包含完整文章 HTML 和绝对 URL。
- FR-7.2 `/sitemap-index.xml` 包含所有内容路由；排除 `/og/*`、`/404`。
- FR-7.3 `/robots.txt` 允许爬取并引用 sitemap。
- FR-7.4 每个页面都有唯一的 `<title>`、meta description、canonical URL 以及 OG/Twitter 元数据；文章使用生成的 1200×630 PNG 卡片。
- FR-7.5 全站输出 `WebSite` 和 `Person` JSON-LD；文章页输出 `BlogPosting`。

### FR-8 主题与页面框架
- FR-8.1 遵循 `prefers-color-scheme`；允许显式选择浅色/深色并持久化到 `localStorage`；加载时不得出现主题错误闪烁。
- FR-8.2 吸顶页头，包含字标、主导航、主题切换和移动端菜单。
- FR-8.3 页脚包含导航、其他渠道链接、版权和 colophon 说明。
- FR-8.4 跳转到内容的链接作为第一个可聚焦元素。

### FR-9 错误处理
- FR-9.1 品牌化 404，包含 Writing、Tags、Home 和搜索链接。

### FR-10 写作工作流
- FR-10.1 新增文章只需一个带有效 frontmatter 的新 Markdown 文件。
- FR-10.2 非法的 frontmatter 会导致构建失败，并给出指明文件/字段的错误信息。
- FR-10.3 草稿文章从列表、feed、sitemap 和 OG 生成中排除。

### FR-11 质量门禁
- FR-11.1 `npm run build` 零错误完成。
- FR-11.2 `npm run check` 报告零 TypeScript/Astro 诊断。
- FR-11.3 自动化链接检查报告零失效内部链接。
- FR-11.4 自动化 SEO 检查验证每个路由的 title/description/canonical/OG。

## 5. 非功能需求

| 领域 | 要求 |
| --- | --- |
| 性能 | 模拟 4G 下 LCP < 1.2 s；CLS < 0.02；内容页面第一方 JS ≤ 12 KB |
| 无障碍 | WCAG 2.2 AA：语义化地标、键盘可操作、可见焦点、4.5:1 文本对比度、支持减少动效、44px 触摸目标 |
| 兼容性 | Chrome、Safari、Firefox、Edge 最新两个版本；iOS/Android；无 JS 时优雅降级 |
| SEO | 静态 HTML、每页一个 H1、可爬取的链接、canonical、sitemap、RSS、结构化数据 |
| 隐私 | 默认无 Cookie、无第三方跟踪器、站点不收集 PII |
| 安全 | 仅 HTTPS、边缘层 CSP 与安全响应头、仓库中无密钥 |
| 可维护性 | TypeScript strict、单一样式表、每个运维任务都有文档 |
| 可移植性 | 可部署到 Cloudflare Pages、Vercel、Netlify、GitHub Pages 或 Docker/Nginx |

## 6. 内容要求

- 十篇英文文章，每篇 ≥ 900 词，覆盖六个标签；其中三篇标记为 `featured`。
- 每篇文章：一个具体的第一手产物（代码、清单、表格或复盘）。
- 描述 120–160 字符，写成对读者的承诺。
- 美式英语拼写；标题句首大写；正文中不使用 emoji。
- 不引用未经核实的统计数据；不编造引语或标识。

## 7. 范围外（v1.0）

评论、账号、CMS 界面、电子商务、多语言、播客/视频、广告、A/B 测试、服务端个性化。

## 8. 依赖与假设

- Node ≥ 20.11，构建时 `npm ci` 需要网络访问。
- 只有在正式上线时才需要域名和托管账号；本地构建/预览不需要。
- Newsletter 服务商（Buttondown/Beehiiv/ConvertKit）在上线后配置。
- 字体从 Google Fonts 加载，并配有可靠的本地回退；无授权成本。

## 9. 发布标准

1. 所有 FR 均已实现，或已明确延期并记录原因。
2. 构建、类型检查、链接检查和 SEO 检查全部通过。
3. QA 报告在 `05-qa-testing/qa-report.md` 中签署通过。
4. 部署手册至少在一个托管平台或通过本地生产预览验证通过。
5. 启动清单在 `07-launch-operations/launch-checklist.md` 中完成。

## 10. 风险

| 风险 | 可能性 | 影响 | 应对 |
| --- | --- | --- | --- |
| 字体 CDN 在部分区域不可用 | 中 | 外观 | 使用度量兼容的系统回退字体栈 |
| 内容增长导致搜索索引膨胀 | 低 | 性能 | 懒加载；约 1,000 篇文章时重新评估 |
| 上线时域名/托管未就绪 | 中 | 延期 | 站点与托管无关；先部署到预览 URL |
| Newsletter 服务商未配置 | 上线时高 | 无法收集邮件 | Mailto 回退 + RSS；第 1 周内完成配置 |
