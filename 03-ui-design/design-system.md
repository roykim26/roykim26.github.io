## 1. 概念

站点应当像一本排版考究的独立杂志，而不是 SaaS 落地页：暖色纸张、浓重的墨色、唯一的朱红点缀、衬线标题、等宽字体的元数据，以及用发丝细线代替卡片。阅读本身是唯一的“英雄区”。

**三个形容词：** 克制、安静、精确。

**反面参照：** 堆满渐变的 SaaS 英雄区、悬浮卡片网格、霓虹暗色模式、蠕动的色块、cookie 横幅、“AI 生成”式的图库素材。

规则：
- 强调色必须**稀缺**：下划线、当前导航圆点、标签悬停、标题里一个斜体词。
- 绝不要用强调色承载长段正文。
- 背景上的文字必须达到 4.5:1（在第 5 阶段验证）。`--ink-faint` 只用于
  ≥ 14px 的场景或非关键元数据。
- 边框分两类：装饰性发丝线用 `--rule`（只承担分隔节奏，不承担识别功能，实测
  ≥ 1.3:1 即可）；**可交互控件的边界**用 `--control-border`（WCAG 1.4.11，≥ 3:1）。

加载：字体**自托管**在 `public/fonts/*.woff2`（latin 子集，静态实例），通过 `@font-face` 声明，
`font-display: swap`；不请求 Google Fonts。回退为 Iowan Old Style / Georgia / ui-monospace。

字号阶梯（token，全站只允许这 9 级）：

```
--fs-meta 0.6875 · --fs-xs 0.75 · --fs-sm 0.875 · --fs-base 0.9375
--fs-body 1.125 · --fs-lead 1.25 · --fs-h3 1.375 · --fs-h4 1.5 · --fs-h2 1.75
```

主标题允许在 `clamp` 区间内插值；行内代码允许 `0.82em` 的相对字号（与衬线正文的 x-height 对齐）。
除此之外不得出现阶梯外的字号。

## 4. 间距、栅格、圆角

- 基准单位 **4px**；阶梯：4、8、12、16、20、24、32、40、48、56、64、72、96。
  区块上下留白统一用 `--section-y: 64px`（移动端 48px）。
- 页面容器：桌面端 `min(1120px, 100% - 48px)`，移动端 `100% - 32px`。
- 正文行宽：68ch；宽幅媒体可突破至 820px。
- 正文内的块级元素（代码块、表格、图片、图注）统一 `32px` 上下间距，段落之间 1.15em；
  **不要用 em 表达**——代码块（14px）与表格（15px）会按自身字号折算成 25px / 27px，
  在长文里显得比其他块更挤。
- 文章页布局 ≥1200px：整块 `max-width: 900px` 居中，内部 `200px | 1fr` 栅格（TOC + 正文），
  间距 64px；标题区 `padding-left: 264px`，使 **H1 左缘与正文左缘重合**。
- 圆角：输入框/按钮 **2px**，图片与卡片 **0**（保持编辑体的锐利感）。
- 边框策略：**一个边界只画一条线**。
  - 结构线（区块之间、列表行之间、页头页脚）→ 1px `--rule`，不加圆角。
  - 容器线（可点击的筛选胶囊、搜索框、分享按钮、标签胶囊、表单输入框）→ 1px `--control-border` + 2px 圆角；
    纯容器（菜单面板、目录框、订阅色带）仍用 `--rule` / `--band-border`。
  - 行内元素（列表标签、作者卡）→ 不加框，靠排版与间距区分。
  - 阴影只用于移动端菜单与搜索对话框。

断点：`640px`（sm）、`900px`（md）、`1200px`（lg，TOC）。移动优先。

## 5. 组件

### Header（页头）
吸顶，高 64px，背景为 92% 不透明度的 `--bg` 叠加背景模糊，底部一条发丝线。左侧：文字标
`Jin Lo`，Instrument Serif 24px，后面跟一个朱红句点。中部/右侧：等宽导航链接
（Writing、Tags、About）、主题切换（日/月图标按钮，44×44）、在 `/blog` 与文章页显示搜索图标。
移动端：文字标 + 主题切换 + 菜单按钮；面板从页头下方滑出。

### Links（链接）
正文链接：`--accent`，1px 下划线，`text-underline-offset: 0.2em`，
`text-decoration-thickness: 1px`；悬停时加粗为 2px 并转为 `--ink`。
导航链接：等宽大写，颜色 `--ink-soft`，悬停 `--ink`；当前页面获得一条
2px 强调色下划线，偏移 6px。

### Tag pill（标签胶囊，可选组件）
等宽 11px 大写，1px `--control-border` 边框，2px 圆角，内边距 4px 8px，透明背景。
悬停：`--accent-wash` 背景，`--accent` 边框与文字。聚焦环 2px `--focus`。
v1.1 起**列表行不再使用胶囊**（改用纯文本标签），该样式仅保留给 `TagPill.astro` 组件。

### Post row（文章行，博客索引）
≥640px 时栅格为 `96px | 1fr | auto`。左：等宽日期（或序号），单行不换行。中：标题
（Instrument Serif 1.5rem）+ 描述（Newsreader，`--ink-soft`，两行截断）+ 一行等宽标签文本
（`Architecture · Performance`，中间用 `·` 分隔，**不再使用描边胶囊**）。
右：等宽阅读时长。行与行以发丝线分隔；悬停时标题转为强调色，并把一个 12px 箭头
滑入视野。整行是一个链接（块级 anchor）。
≤640px：日期与阅读时长占首行两端，标题与描述独占第二行，避免重叠。

### Featured（精选区）
在容器内通栏，**7:5 两栏**：左栏是大标题（Display L），右栏是描述与元信息行（日期 · 阅读时长 · 标签）。
不再使用右侧“图版”装饰；两栏底部对齐，靠字号差建立主次。标签 `Featured essay` 用统一灰色
`.eyebrow` 标签（与所有区块标题同一写法），不使用强调色。

### Buttons（按钮）
主要按钮：墨色背景、纸色文字、2px 圆角、等宽大写 11px、内边距 12px 20px。
悬停：强调色背景、仍为纸色文字（不能用纯白：暗色强调色上的白字只有 2.76:1）。次要按钮：1px 墨色边框、透明背景，悬停时以 8% 墨色填充。
次级入口（如首页“About the author”）使用 `.link-arrow`：等宽大写文字链接，不与主按钮争视觉重量。
聚焦：2px `--focus`，偏移 2px。最小点击目标 44px。

### Form（订阅表单）
订阅表单输入框：透明背景，1px `--ink` 下边框，衬线 18px，占位符 `--ink-faint`；
独立订阅页输入框用 1px `--control-border` 完整边框。提交按钮在右侧，墨色填充。移动端纵向堆叠。
成功/错误消息是 `role="status"`，错误用强调色，不使用 toast。

### TOC（目录）
等宽 11px 大写标签 “Contents”，链接为 14px Newsreader，左侧一条发丝竖线；当前项
有 2px 强调色竖条与 `--ink` 颜色，非当前项为 `--ink-faint`。在 <1200px 时折叠为
`<details>`。

### Code block（代码块）
全宽深色块（`--code-bg`），圆角 2px，等宽 14px，内边距 20px，右上角语言
标签为 10px 大写 `--ink-faint`；**不换行**，超出时横向滚动。
`<pre>` 内 `white-space: pre`（覆盖 Shiki 内联的 `pre-wrap`），`overscroll-behavior-x: contain`
避免滑到尽头触发浏览器返回手势。
横向可滚动时右缘给出提示：代码块用 24px 渐隐（`mask-image`），表格用 22px 内阴影——
表格右侧常是空白单元格，纯渐隐看不出来。提示由 `data-scroll="start|middle|end"` 驱动，
滚到最右端即移除，文字不会被永久淡化；不可滚动时属性不存在，也就没有提示。
行内代码：`--bg-raised` 背景，1px `--rule` 边框，0.82em 等宽字体，内边距 1px 5px。

### Blockquote（引用块）
左侧 3px 强调色竖线，衬线斜体 1.25rem，`--ink-soft`，左内边距 24px，
不使用引号装饰。

### Progress bar（进度条）
2px，固定在顶部，强调色，宽度 = 滚动比例；在减少动态效果时隐藏？不——
它不是动效，保留；通过 rAF 更新。

### Search dialog（搜索对话框）
由页头触发的浮层（最大宽度 640px），包含输入框、结果列表、键盘导航，
`Escape` 关闭，焦点先被限制在浮层内、随后恢复。JS 关闭时在 `/blog` 回退为一段
内联说明。使用 Pagefind UI，并配自定义 CSS 变量。

## 6. 动效

- 时长：120ms（悬停）、200ms（菜单/浮层）、320ms（主题切换，仅颜色）。
- 缓动：`cubic-bezier(0.2, 0.7, 0.2, 1)`。
- 只有 `transform`、`opacity`、`color`、`background-color`、`border-color` 参与动画。
- `prefers-reduced-motion: reduce` 会移除所有过渡与平滑滚动，但状态变化仍即时可见。
- v1 不做滚动触发的入场动画（它们会损害感知性能与 CLS）。

## 7. 图像

- **不使用图库摄影。** 视觉趣味来自字体、线条与留白；v1.1 起不再使用斜纹“图版”装饰，
  首页右栏改为数据账簿（Essays / Topics / Since）。
- 作者头像：生成的字母组合图版，而不是图库人脸。
- 文章图片（frontmatter 中可选）：暖色调，3:2，图注使用等宽 12px。
- OG 卡片：1200×630，纸色背景，墨色标题（自动换行，最多 4 行），朱红细线，
  左下角文字标，右下角标签 + 日期。

## 8. 无障碍约定

- 每个可交互元素都有可见焦点（2px `--focus`，偏移 2px），永不移除。
- 跳转链接在聚焦时出现在左上角。
- 对比度（WCAG 2.2 AA）：正文 ≥ 4.5:1，大号展示文字 ≥ 3:1；
  可交互控件的边界与焦点指示相对相邻颜色 ≥ 3:1（1.4.11）。装饰性分隔线不在此列，
  但需 ≥ 1.3:1 以免完全消失。全部实测值见 [contrast-audit.md](contrast-audit.md)。
- 触摸目标 ≥ 44×44 CSS px（导航、切换、分享、菜单）。窄屏（≤900px）下分享按钮、
  折叠目录条、目录条目、作者卡链接也补到 44px。页脚与正文中的行内文字链接按
  WCAG 2.5.8 的间距例外处理：自身高度不足 44px，但四周留白足够，相邻目标不重叠。
- 长文辅助元素保持克制：只有顶部 2px 阅读进度条与折叠目录，不额外加悬浮“返回顶部”；
  页头吸顶且始终可展开菜单，回到导航不需要长距离回滚。
- 纯图标按钮带 `aria-label`；图标为 `aria-hidden`。
- 表单：使用可见的 `<label>` 或 `aria-label`，错误文本通过 `aria-describedby` 关联，
  不使用仅靠占位符的标注方式。
- 动效与主题遵循用户偏好；不使用自动播放的媒体。

## 9. 暗色模式

通过 `<html>` 上的 `data-theme="dark"` 实现，由按钮切换，并在绘制前的内联脚本中
从 `localStorage` 或 `prefers-color-scheme` 初始化。深色表面是暖黑而非蓝黑；
强调色提亮为 `#F07A52` 以保证对比度。代码块更深。边框变为 `#3A3530`（在 `#121110` 上
约 1.56:1，保证发丝线可见）；可交互控件边界用 `#6E685C`（约 3.41:1）。订阅色带用 `#2A251F`
并加 1px `--band-border`，避免与页面融成一片；色带内焦点环改用 `--band-ink`（浅色主题的
深蓝环在墨色底上只有 2.88:1）。
不使用纯白文字。
